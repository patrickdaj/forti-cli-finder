# FortiManager's schema against the bundles

Generated by `make schema-diff` (`tools/diff_schema.py`), read-only: it reads the brain's
`fmg-syntax-<train>-device.json` and the shipped bundles and changes nothing. The full
disagreement lists land in `work/schema-diff-7.6.json` and `work/schema-diff-8.0.json`
(gitignored). Pairs: 7.6 is `site/data/fortios.json` against `fmg-syntax-7.6-device.json`;
8.0 is `site/data/fortios-8.0.json` against `fmg-syntax-8.0-device.json`.

## How the join works

Config tables join on path. A bundle config entry carries its own parameters and those of
its nested `config` sub-tables in one flat `x[]`; a nested parameter has `t`, the **leaf**
name of the sub-table it sits in (`sla`, never `health-check > sla`). The schema nests
instead, under `subobj`. Both sides are flattened to `(leaf, name)`. Where a table has two
sub-tables with the same leaf name (`system sdwan` has `sla` under both `health-check` and
`service`) the candidates merge, and a name with more than one candidate on either side is
counted as ambiguous and **not compared** (124 parameters in 7.6, 70 in 8.0) rather than
guessed. Parameters equal to a sub-table's edit key would be counted as keys, not
bundle-only; there were none, because the schema lists keys among its attributes too.

"Agree" on type includes 10066 (7.6) and 10792 (8.0) pairs that agree only through the
vocabulary below. Every disagreement lands in `likely-parser`: the 7 `_`-prefixed
attributes per train (`__change_ip` on the `log fortianalyzer*` tables) are all schema-only, so none disagrees on a value.

The bundle-only tables are mostly real: the Finder parses `certificate local`,
`firewall acl`, `dpdk global` and the like, which a FortiManager managing a 70G / FortiGate-VM
does not expose. They are not parser faults.

### Two things to know before acting on a class

* **`excluded: true` does not mean FortiManager-only.** The brief proposed it as the
  `schema-excluded` marker. It is set on 5184 of the 5414 schema attributes that carry an
  option list, including `system sdwan fail-detect`, and the bundles agree with the schema on 4136 of those. The tool therefore does
  not use it; only a leading `_` marks `schema-excluded`. The flag is kept in each JSON
  item as `excl`. Somebody who knows what FortiManager means by it should say.
* **Defaults are compared as text.** A number in the schema and `"80"` in the bundle agree.

A `user` or `option` pair that fails this table is a real mismatch and is reported.
Default values carry their own vocabulary, tallied the same way: a number against its text
(2303 / 2373), an address default without its mask (`0.0.0.0` against `0.0.0.0 0.0.0.0`;
73 / 83), a password default that is ciphertext in the schema and absent in the PDF
(155 / 10), `''` against nothing (39 / 40), and a zero default the schema leaves implicit
(bundle `0`, schema none).

## What the `likely-parser` disagreements look like, ranked

Counts are 7.6 / 8.0. The pages are the PDF page (`pg`) of the bundle entry in that train.

1. **Option list absent from the bundle, 518 / 536.** The parameter is typed `option`, the
   bundle has no `o` at all, the schema lists the options. 195 tables in 7.6; the worst
   pages are 2682 (25 parameters), 1032 (23), 1543 (14). Of the 518, 376 have the full list
   in the table's own `config` synopsis (`set IPS-logs [enable|disable]`), so they are
   recoverable without the schema. Examples: `alertemail setting` `IPS-logs`,
   `antivirus-logs`, `filter-mode` (p.132, 8.0 p.141: schema `category`/`threshold`).
2. **Option list is a strict subset, 236 / 261.** The bundle has some options, the schema
   has more. `antivirus profile` `cifs > archive-log` (p.140: schema also has `mailbomb`,
   `nested`, `timeout`, `unhandled`), `ftp > fortisandbox` (p.140), `http > emulator`
   (p.140). Consistent with an option table cut at a page break.
3. **Space inside a default, 191 / 212.** A value wrapped at a line or page and rejoined with
   a space, or a list that lost its spaces. `antivirus profile` `fortisandbox-mode` (p.140:
   `analytics- everything` against `analytics-everything`), `authentication scheme`
   `digest-algo` (p.199: `md5 sha- 256`), `application list > entries` `popularity`
   (p.184: `12345` against `1 2 3 4 5`).
4. **Default missing in the bundle, 158 / 161.** The schema has one, the PDF row does not
   print it (or the parser dropped it). `diameter-filter profile` `command-code-range`
   (p.249, schema `256-1677213`), `firewall address` `associated-interface` (p.454,
   `any`), `firewall central-snat-map` `orig-port`/`nat-port`/`dst-port` (p.472, `0`).
5. **Option name cut at a line wrap, 125 / 148.** Each half of a wrapped option name becomes
   a separate option. `antivirus profile` `fortisandbox-mode` (p.140:
   `analytics-`, `everything` for `analytics-everything`), `casb user-activity > operations`
   `action` (p.227: `new-on-not-`, `found`), `dlp settings` `db-mode` (p.274:
   `remove-`, `modified-then-`, `oldest`). In 8.0, `authentication scheme` `captcha-vendor`
   (p.216) loses four.
6. **Footnote marker left in a default, 54 / 51.** `enable **`, `512 **`, `wan- extension **`.
   `automation setting` `max-concurrent-stitches` (p.206, `512 **`), `extension-controller
   extender-profile` `extension` (p.327), `ips global` `cp-accel-mode` (p.781). The `**`
   also marks values that genuinely differ by model, so stripping it is not enough
   for `antivirus quarantine` `destination` (p.176: `disk **` against schema `NULL` in 7.6,
   `disk` in 8.0).
7. **Type mismatch, 12 / 16.** Real ones: `router route-map` `match-tag`, `set-weight`,
   `match-metric` (p.1181: bundle `integer`, schema `string`), `router static` `vrf` (p.1188,
   `integer` against `user`), `user ldap` `source-ip` (p.2137, `string` against `ip4`),
   `log fortianalyzer setting` `preshared-key` (8.0 p.868, `password` against `string`).
8. **Option missing from the schema, 14 / 9.** The PDF has options FortiManager's device
   schema does not: `dlp profile rule` `proto` (p.266), `firewall DoS-policy anomaly`
   `action` `proxy` (8.0 p.405). Probably a model difference, not a fault; low priority.
9. **Default value differs, 11 / 14.** A mixed bag: `system global` `gui-rest-api-cache`
   (p.1543, `enable` against `disable`), `vpn ipsec phase1` `signature-hash-alg` (p.2249,
   the PDF keeps one of four), `system automation-action` `message` (p.1425, long text
   with a wrapped space).

Patterns 1 to 6 account for 1282 of 1320 (7.6) and 1369 of 1410 (8.0). Nothing here
has been fixed: this task changes no parser, and a rule for each pattern should be checked
against `tools/parse_fos.py` before it is written.
